# Introduction

**Development tools of VacuiOS** help to manage the source tree of VacuiOS components (Core and SDK)
in a flexible way. They are developed in Golang (as mentioned in the ["foundation.md"](../foundation.md)
document).

- **Victus** is a C/C++ build orchestrator sitting on top of GNU Make.
